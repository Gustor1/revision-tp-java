# Révision TP Java (PR70)

Site de révision pour l'évaluation de TP Java sur papier : lecture de code, textes à trous et QCM, organisés dans l'ordre des TP (bases et String, héritage et polymorphisme, exceptions, collections, Swing, fichiers, dessin, plus court chemin).

- 94 exercices corrigés et expliqués (le code de chacun a été compilé et exécuté avec Java 21)
- une fiche de cours par chapitre
- un examen blanc imprimable avec son corrigé
- une page de couverture des TP

En ligne : https://gustor1.github.io/revision-tp-java/

En local : ouvrir `index.html` dans un navigateur, sans installation. La progression est enregistrée dans le navigateur.
